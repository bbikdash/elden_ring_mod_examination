These CSVs and comparison report were generated in Smithbox 2.1 by loading the original Unlocked Weapon Skills v1.06 with the corresponding Elden Ring `regulation.bin` v1.06. As such, all the of the modified params rows map properly to the corresponding params in the `regulation.bin`.

The problem with comparing the original mod to the v1.16.1 `regulation.bin` is that there are many new entries in the `BehaviorParam_PC.csv`. These entries resulted in modded entries with incorrect refIds.

To re-iterate, the CSVs in this file are the *modified* versions relative to vanilla v1.06.
